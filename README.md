# Что произойдет

0. Все создается в зоне ru-central1-e
1. Будет создана инфраструктура из 1 виртуальной машины на ubuntu 24.04
2. Будет создана VPC
3. Будет создана подсеть
4. Запрос ввода с клавиатуры ID облака и папки в Yandex Cloud

> [!NOTE]
> Для работы **необходимо** создать сервисный аккаунт с правами Editor, создать для него IAM токен и положить ```authorized_key.json``` рядом с остальными файлами. 
> Так же для работы S3 Bucket необходимо создать в Object Storage S3 Bucket и назначить права ```storage.editor``` ранее созданному сервисному аккаунту и создать ему статический ключ доступа.
> Полученные ```secret_key``` и ```access_key``` необходимо записать в файл ```backend.tfvars``` и положить рядом с остальными файлами:

```
#=== backend.tfvars===
bucket        = "название вашего S3 Bucket"
secret_key    = "ключ доступа созданный ранее"
access_key    = "ключ доступа созданный ранее"
```

По итогу должна быть такая структура:
```
./terraform-diploma/
    |ansible.tf
    |authorized_key.json
    |backend.tf
    |backend.tfvars
    |main.tf
    |providers.tf
    |template.tpl
    |vars.tf
```
